# Windsurf / Devin Skills

This directory mirrors the active Devin skills from `.agents/skills/` for compatibility with Devin Desktop and Windsurf-derived local scanning.

Official Devin documentation lists both paths as supported:

- `.agents/skills/<skill-name>/SKILL.md`
- `.windsurf/skills/<skill-name>/SKILL.md`

The canonical source remains `.agents/skills/`, but this mirror helps local Devin Desktop sessions discover the same project skills when they are already reading `.windsurf/rules`.
