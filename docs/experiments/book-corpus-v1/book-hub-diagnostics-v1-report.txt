== Definitions ==
top-K count = queries that ranked the chunk's atom within the first K of the frozen top-10; repeated text is one atom, counted once per query under its first key (aliases listed)
occurrences = query-hit pairs (a query contributes up to K); distinct = different atoms among them
labels: E2/E1 judged evidence, C0 judged confounder, U unjudged for that query (not assumed irrelevant)
tokens = production weighted tokens of MonadaMemoryOptions.defaults(): original = normalized terms (weight 1.0), expansion = lexical expansions (weight 0.25); stop words already removed
topTok = occurrences of the chunk's most frequent original token (token not named); nz = non-zero buckets of the stored vector; maxAbs = largest |component|; norm = L2 norm
centroidCos = cosine (double arithmetic) of the stored vector with the mean of all stored chunk vectors; a diagnostic of vector geometry, not a production score
bucket contribution = q[i]*c[i]/(|q||c|) exactly as the production cosine sums it; pos/neg = sums of positive/negative contributions; shared = buckets non-zero in both vectors
cover = distinct original query tokens also among the chunk's original tokens / distinct original query tokens
bucket tokens: query tokens hashing to the bucket (+ = expansion), m = their occurrences in the chunk's weighted tokens, o = other distinct chunk tokens colliding in that bucket
rank (decomposition) = rank among all atoms in the recomputed ranking; ranks 1-10 equal production (parity), deeper ranks come from the same recomputation
