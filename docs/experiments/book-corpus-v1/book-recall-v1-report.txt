== Definitions ==
relevant = judged EVIDENCE (grade 1 partial, grade 2 direct) of the query; chunks with identical text share one atom and count once, under their first key
denominator = answerable queries of the group; NO_ANSWER queries have no relevant set, are not in P/R/Hit/MRR and are reported as false hits instead
P@K = relevant hits in top-K / K (a short result list still divides by K); R@K = relevant atoms in top-K / relevant atoms; Hit@K = any relevant in top-K; Hit@K(direct) = any grade-2 evidence in top-K; MRR = mean 1/rank of the first relevant hit (0 when none in top-10)
labels: E2/E1 judged evidence, C0 judged confounder, U unjudged for this query (not assumed non-relevant; counted separately)
false hit = a NO_ANSWER query that returns any chunk at the evaluated threshold (-Infinity, so every non-empty top-K is one)
failure classes (first match wins): NO_RELEVANT_RESULT no evidence in top-10; DISTRACTOR a judged confounder above the first evidence; CHUNK_BOUNDARY_GAP an unjudged chunk adjacent (ordinal +-1) to evidence above the first evidence; WRONG_RANK evidence below rank 1 behind other chunks; MULTI_EVIDENCE_GAP rank 1 is evidence but some evidence is missing from the top-10; NONE; FALSE_POSITIVE / ABSTAINED for NO_ANSWER
