== What is measured, and what is not ==
ranking feedback: an explicit statement by the host that, for one exact query text, an atom should rank higher (POSITIVE) or lower (NEGATIVE); it changes scores, never stored text
explicit new note: content the host adds with remember(); it is a new atom next to the old ones and replaces, deletes or versions nothing
execution outcomes: not used or measured here
not shipped: the Store does not detect wrong answers, does not choose feedback, does not add or correct facts by itself and does not generalize feedback beyond the exact query key
metrics: as in the book recall report (P@K, R@K, Hit@K over judged evidence; MRR; NO_ANSWER false hits); labels E2/E1 evidence, C0 confounder, U unjudged
outcome per group: BETTER/WORSE by MRR, ties broken by Hit@10 then R@10; SAME when all three are equal; no improvement is required
regression: an answerable query whose RR, any Hit@K or R@10 is lower in treatment than in control
contamination: a query without its own feedback (HOLDOUT, DEV without feedback, confusable variant) whose top-10 differs from control in any atom or score
chunk keys below are relative to <corpus>/<policy>/ of the inputs
