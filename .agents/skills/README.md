# Monada Agent Skills

This directory contains Devin-compatible skills for Monada Resonance Store.

Devin discovers skills from `.agents/skills/<skill-name>/SKILL.md` automatically. Use these skills for repeatable project workflows and implementation constraints.

## Skills

| Skill | Use when |
| --- | --- |
| `monada-agent-task-workflow` | Creating Issues, PR plans, or review feedback with Spec Context. |
| `monada-resonance-algorithm-design` | Changing encoding, lexical enrichment, query keys, scoring, or ranking. |
| `monada-storage-io-design` | Changing persistence, manifests, logs, vectors, indexes, or compatibility. |
| `monada-evaluation-statistics` | Adding metrics, datasets, diagnostics, A/B reports, or regression checks. |
| `monada-java-26-implementation` | Implementing Java 26 code, Gradle modules, APIs, and tests. |
| `monada-data-structures` | Adding compact vectors, indexes, caches, or new data structures. |
| `monada-performance-optimization` | Optimizing after a measurable baseline exists. |
| `monada-ml-dl-integration` | Planning model-based encoders, embeddings, ONNX, or learned ranking. |
